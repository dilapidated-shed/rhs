# RHS-1 decision rule before scored execution

Candidate: Qwen/Qwen2.5-Coder-0.5B-Instruct, an instruction-tuned causal language model. Resolve the model repository's main revision once to an immutable 40-character commit before inference; use that same revision for weights and tokenizer. Record revision, configuration, tokenizer, chat template, package versions, system instruction, rendered prompts, input/output token IDs and raw responses. CPU float32, eager attention, two threads, seed 1701, greedy decoding, maximum 32 new tokens, no truncation, no training, no threshold selection. Only the first stripped response line exactly equal to AGREEMENT, CONTRADICTION or UNKNOWN is a decision; anything else is PARSE_FAILURE. All decisions are model-only estimates.

The test partition contains all related variants of all eight mechanism families. Each has two implementations, three source presentations (selected original core, harmless local-name/whitespace change, single-call helper wrapper) and two opposing claims: 96 supported packets, independently expected 48 agreements and 48 contradictions. Eight vague claims add unsupported cases. Correct/faulty implementations share each claim; each implementation is tested under truthful/misleading claims. No test label is used for fitting, model selection, prompt revision or calibration. This is a public-corpus pilot with possible model contamination, not a hidden generalization benchmark.

Candidate inputs: legitimate function/macro name and explicit human claim, selected implementation plus safe observer, and actually captured input/output/effect rows. Neutral content-derived IDs convey no labels. Exclude mechanism filenames, provenance comments, selectors, diagnostic outputs, grading labels, declared-relation IDs and exact checker outputs. Retain every packet and full rendered prompt.

Simple baselines always answer AGREEMENT or CONTRADICTION. Report 96 supported outcomes, false positives on 48 agreements, missed contradictions on 48 contradictions, UNKNOWN/PARSE_FAILURE on supported packets, and UNKNOWN on eight unsupported packets. Never count unavailable models, missing calls, compile failure, timeout, crash or unsupported NaN as detection.

The independently declared exact relations use finite observation rows, not a model's interpretation of the name. Original diagnostic reductions are run independently at O0 and O2. Every transformed observer is recompiled/executed at both levels; all six observations for a particular mechanism implementation must match. The model never receives those diagnostic control outputs. The grader consumes already-produced findings; reversing only the grading labels must preserve findings byte for byte.

Scoring is categorical. A false positive is a CONTRADICTION decision on an independently expected agreement. A missed contradiction is any decision other than CONTRADICTION on an independently expected contradiction, including UNKNOWN and PARSE_FAILURE. Abstentions and parse failures are also counted separately over the supported cases. Unsupported cases are reported separately, not included in supported accuracy. This clarification does not alter the fixed model decision rule or prompt.
