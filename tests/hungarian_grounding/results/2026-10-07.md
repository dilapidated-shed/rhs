# RHS-2: Hungarian names and observed computations — 2026-10-07

Repeated prefix geometry is supported on these fixtures. Correspondence with
full-word meaning is weaker and varies by family. Useful name/computation
disagreement detection is **not supported by the predeclared rule**: its primary
macro balanced accuracy is 47.9–50.0%, against a 50.0% baseline. This is a negative
result about this fixed embedding/decision path, not a claim that these models
can never represent programming meaning.

All five requested models executed on GitHub-hosted Ubuntu. None was unavailable.
Every captured score object was recomputed offline from its vectors and matched
exactly. A second execution reproduced the counts, condition/family errors and
paired-intervention results. The unchanged historical probe is a setup comparison,
not the main deliverable.

All related examples in a context bundle share their partition. Three bundles
supply prototypes; six are held out. Two stems, spelling forms and several
claims for one computation are correlated repetitions, not independent programs.
Ground truth comes from checked integer fixture computations, independently of
embeddings. Positions are zero based and row-major. WORD/DWORD mean unsigned
truncation modulo 2¹⁶/2³², independently of host C widths. No text counting or
ambiguous character-count ground truth is used.

Seven [declared primitives](../primitives.tsv) pair cb/ByteCount, ce/ElementCount,
i/Index, rw/RowNumber, col/ColumnNumber, dw/Unsigned32BitValue and
w/Unsigned16BitValue. Nonsense prefixes match character length, not necessarily
token count. Misleading substitutions cycle to the next plausible prefix
**within the family**. We retain scores against both literal spelling and intended
replacement label. They are diagnostic labels, not independent behavioral truth.
Nonsense has no asserted programming meaning and is excluded from agreement truth.

There are 24 held-out edges for six fitted facets plus four separate element-count
edges, each in abbreviated/full-word/nonsense/misleading form. The primary corpus
crosses every plausible claim with every behavior in its family, in abbreviated
and full-word forms: 136 held-out pairs, 56 agreeing and 80 disagreeing.

## Inputs and fixed scoring

| Question or condition | Information received by encoder | Fixed decision |
|---|---|---|
| textual transformation | off/on identifiers embedded separately | difference nearest to training abbreviated difference prototypes |
| full-word correspondence | identifier differences only | difference nearest to training full-word difference prototypes |
| name only | literal identifier | nearest of seven raw explicit meaning vectors; facet diagnostic |
| computation/observation only | computation text and numeric observed value | nearest to the same meaning vectors; behavior-facet diagnostic |
| primary agreement | the preceding two embeddings independently | agree iff inferred facets match; abstentions are errors |
| exploratory combined text | name, computation and observed value in one string | behavior-facet classification against the same anchors; not a direct agreement classifier |

No input contains a truth label, partition or family field. Computation variable
names remain visible; this experiment does not remove lexical cues from source.
For example, the byte-count computation input is literally:

    element_count = 7; bytes_per_element = 2; return element_count * bytes_per_element; Observed return value: 14.

Primary anchors are raw E(meaning). Relation-anchor diagnostics use
E(meaning) - E("quantity"); full-word correspondence uses mean training
E(FullWordStem) - E(Stem). These objects are not interchangeable. All coordinates
and comparisons stay within the originating model. Exact zero vectors and cosine
ties within 1e-12 abstain. The primary statistic averages the three family balanced
accuracies, each (true-positive rate + true-negative rate)/2.

The literal-prefix/full-word lookup baseline recovers 24/24 transformations without
an encoder and scores 0/24 against misleading intended replacement labels.
Always-agree gets 56/136 ordinary correct and 50% balanced accuracy; always-disagree
gets 80/136 and also 50%. Ordinary accuracy alone rewards the negative imbalance.
The independent one-hot fixture oracle passes the scorer at balanced accuracy 1.0;
the zero-vector mutant scores 0.0. Dimension, tie, partition and frontend-effect
negative controls also execute.

## Tokenization and model space

The complete aBcd / aBcD / ABcd / ABcD square is retained. MiniLM and BERT uncased
tokenize all four identically as [CLS] abc ##d [SEP], IDs [101,5925,2094,102].
Their two final-case directions are exactly zero, and all four old square edges
are zero. CodeBERTa, CodeBERT and BERT cased retain case. Their final D-minus-d
alignments in the primary run are 0.8328167924, 0.5089648787, 0.8094793889.
Undefined zero directions remain undefined. All new relation directions are
nonzero. Exact tokens, masks, norms and vectors are preserved.

Nonsense/abbreviation token counts match on only 12/28, 16/28, 11/28, 24/28,
11/28 held-out pairs in model-table order, including element-count. Equal token
counts do not make token identities equal. [Token-length residuals](token-length-matching.tsv)
and all raw token sequences expose the imperfect matching. The byte-level
tokenizers also change token counts across the capitalization controls.

Each encoder independently uses CPU float32, eval mode, seed 0, two threads,
batch size one; attention-mask mean pooling of last_hidden_state includes special
tokens. Inputs over 256 tokens fail instead of truncating. MiniLM uses the same
raw AutoModel pooling as the historical probe, not a substituted sentence
transformers pipeline. The saved model configs and vector lengths identify each
space. No coordinates or prototypes are pooled across models.

## Consequence for RHS-1

Repeated prefix directions can serve as lexical controls or candidate features.
RHS-2 does not validate a gate that accepts a program's claim from Hungarian
geometry. Keep explicit units and independent behavior observations as ground
truth. Full-word recognition and prefix classification can coexist with failure
when behavior changes under a fixed name. Any future verifier needs its own
predeclared behavioral acceptance test; this small corpus does not prove general
code understanding.
